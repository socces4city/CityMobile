# Mystic Oracle - Divination App

A comprehensive divination application featuring multiple mystical practices for spiritual guidance and insight.

## ✨ Features

### Divination Methods
- **Tarot Cards** - Draw from the Major and Minor Arcana with multiple spread options (Single Card, Three Card, Celtic Cross)
- **Norse Runes** - Cast ancient Viking runes for wisdom and guidance
- **I Ching** - Consult the Chinese Book of Changes with hexagram readings
- **Numerology** - Calculate your Life Path and Destiny numbers
- **Crystal Ball** - Receive mystical visions through scrying
- **Astrology** - Discover your zodiac sign traits and daily guidance

### Modern Experience
- Beautiful, mystical UI with cosmic themes and animations
- Responsive design that works on all devices
- Smooth animations and transitions using Framer Motion
- Dark theme with ethereal gradients and glowing effects

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd divination-app
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`
